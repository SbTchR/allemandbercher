## Deux constructions de base

- **W-Frage** : mot interrogatif + verbe + sujet, sauf si le mot interrogatif est déjà le sujet. Exemple : *Wo wohnst du?*
- **Ja/Nein-Frage** : verbe + sujet. Exemple : *Wohnst du in Bern?*

L’allemand n’ajoute pas une formule équivalente à « est-ce que ». Pour poser une question oui/non, le verbe conjugué passe simplement devant le sujet.
