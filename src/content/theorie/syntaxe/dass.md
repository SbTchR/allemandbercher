## À retenir

Après **dass**, le verbe conjugué va à la **fin**. Une virgule précède **dass**.

| Construction | Observe le verbe rouge | Sens |
| --- | --- | --- |
| Présent | Ich denke, dass Lina nett <span class="mark-verb">ist</span>. | Je pense que Lina est gentille. |
| Passé composé | Ich weiss, dass sie <span class="mark-verbal-tail">gekommen</span> <span class="mark-verb">ist</span>. | Je sais qu’elle est venue. |
| Modalité | Ich glaube, dass sie <span class="mark-verbal-tail">kommen</span> <span class="mark-verb">kann</span>. | Je crois qu’elle peut venir. |

**Deux verbes ?** Le participe passé ou l’infinitif (violet) précède le verbe conjugué (rouge).

### Donner son avis

**denken** = penser · **glauben** = croire · **finden** = trouver · **wissen** = savoir

| Demander | Répondre |
| --- | --- |
| Was denkst du über Lina? | Ich denke, dass Lina nett ist. |
| Wie findest du den Film? | Ich finde, dass er spannend ist. |
| Was weisst du über Tom? | Ich weiss, dass er gern liest. |
| Denkst du, dass Tom nett ist? | Ja, bestimmt. |
| Findest du, dass der Film gut ist? | Nein, ich finde nicht. |

| Ton avis | Réponses utiles |
| --- | --- |
| D’accord | Ja, bestimmt. · Ja, sicher! · Ja, genau. |
| Pas d’accord | Nein, ich denke nicht. · Nein, ich finde nicht. · Nein, sicher nicht. · Nein, das stimmt nicht. |
| Tu hésites | Vielleicht… (peut-être) · Ich weiss es nicht. · Keine Ahnung. (aucune idée) |
