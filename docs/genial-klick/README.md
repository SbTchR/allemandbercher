# Analyse interne Genial Klick

Ce dossier sert de reference interne pour ameliorer `allemandbercher.ch` avec des exemples adaptes a la progression Genial Klick utilisee en 9H, 10H et 11H.

Les fichiers source restent locaux dans `genial_klick/` et ne doivent pas etre publies ni versionnes. Les syntheses ci-dessous ne remplacent pas les manuels: elles indiquent les champs lexicaux, structures et patrons de phrases utiles pour creer des exercices originaux ou des exemples de theorie.

## Methode

- Les six PDF ont ete extraits page par page avec PDFKit macOS, apres verification que chaque page contenait du texte exploitable.
- Les sommaires des Kursbuch ont servi de base pour les themes, objectifs, champs lexicaux et points de grammaire.
- Les pages de bilan et les Arbeitsbuch ont ete utilisees pour confirmer les capacites attendues des eleves.
- Les CSV ont ete regroupes par chapitre pour identifier les mots, verbes et phrases-types deja travailles.
- Les documents de ce dossier ne conservent pas les textes longs, dialogues, consignes completes, exercices ou enchainements d'activites des manuels.

## Regles d'utilisation

- Utiliser les mots isoles, champs lexicaux, patrons syntaxiques et courtes phrases-types comme contraintes de niveau.
- Creer des phrases, mini-dialogues, textes courts et exercices entierement originaux.
- Ne pas reprendre un exercice Genial Klick, une consigne complete, un texte de lecture, un dialogue ou une sequence de page.
- Quand une page de theorie demande un exemple, choisir le niveau le plus bas ou la structure apparait deja.
- Quand un exercice interactif vise un chapitre, utiliser son vocabulaire et ses structures, puis varier les personnes, lieux, objets et situations.
- Si un besoin depasse la progression recensee ici, signaler l'ecart dans la page ou choisir un exemple plus simple.
